# Multifactor-model-using-tree-based-model
Built a 12-factor alpha library (Rank IC/IR); identified 20-day volatility as top predictor. Trained RF/XGBoost models achieving 0.0191 out-of-sample IC. Built max-Sharpe and risk-parity portfolios via Ledoit-Wolf covariance; 5-day rebalancing cut Sharpe erosion to 16%. Isolated +0.79% active alpha (IR 0.202) with stress testing.
